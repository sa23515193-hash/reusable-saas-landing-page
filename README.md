# SaaS Landing Page Components

A responsive SaaS landing page built with React and Tailwind CSS, using reusable UI components and a polished, modern layout.

## Features
- Reusable `Navbar`, `Badge`, `FeatureCard`, and `PricingCard` components
- Responsive hero section and dashboard preview
- Feature highlights, workflow section, and three pricing tiers
- Mobile-friendly navigation and responsive grids
- Tailwind utility styling with custom CSS for typography and background effects

## Tech Stack
- React 18
- Vite
- Tailwind CSS (CDN configuration for quick setup)

## Run Locally
1. Install Node.js (18+ recommended).
2. Extract this ZIP and open the project folder in a terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Production Build
```bash
npm run build
npm run preview
```
